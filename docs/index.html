2. Năm đặc tính NIST

  1. On-demand self-service: Sinh viên tự tạo Codespace trực tiếp trên GitHub mà không cần quản trị viên.
  2. Broad network access: API có thể được truy cập từ điện thoại thông qua URL HTTPS khi cổng ở chế độ Public.
  3. Resource pooling: Codespace được cấp phát từ hệ thống tài nguyên đám mây dùng chung của GitHub.
  4. Rapid elasticity: Có thể nhanh chóng khởi tạo, thay đổi cấu hình hoặc dừng Codespace để giải phóng tài nguyên.
  5. Measured service: GitHub cung cấp Billing Usage để theo dõi thời gian tính toán và lưu trữ.
